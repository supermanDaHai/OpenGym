设计说明（为什么这样改）

1. 配色从「深色霓虹」改为「浅色明亮」。 原后台是 #070b14 深黑底 + 青绿荧光，长时间盯数据容易疲劳、也显"廉价"。新方案用近白画布 #f4f6f9 + 纯白卡片 + 发丝级边框 + 极淡阴影，信息像"纸面报表"一样清晰，主色用契合健身的祖母绿 #10b981 做点缀而非铺满。

2. 看板不再"挤在一块"。 原 KPI 用 minmax(150px,1fr) 一行硬塞 7 个、图表 minmax(300px,1fr) 几乎贴边、padding 仅 14px。新版：KPI 固定 4 列、图表 2×2 大卡、间距统一 18px、内容限宽 1320px 居中——呼吸感来自留白，不是装饰。

3. 弹窗从「底部抽屉」改为「居中弹窗」。 原后台所有弹层都复用 App 的移动端 openSheet，默认从屏幕底部滑出（为手机单手操作设计）。但这是一个 Web 管理后台：桌面端居中弹窗视线更自然、信息密度更高、不遮挡整屏上下文。右下角开关可实时切换两种风格对比。

  • 用户详情 / 创建邀请码 → 改为居中对话框（带标题栏、关闭按钮、底部操作区）。
  • 禁用账号 / 吊销邀请码 这类危险操作 → 居中确认框，红色强调。
  • 移除了原有的移动端响应式 hack（侧栏变顶栏、表格列折叠），因为未来只做 Web 后台。
